# StrMatch — гибридная компонента (1С++ ВК + расширение SQLite)

Нечёткое (фонетическое) сравнение русских строк. Алгоритм `CStrMatch`
Александра Ракунова (Sk0rp), MIT, github.com/5k0rp/StrMatch.

Собрано как **гибрид** по замыслу Djelf: одна DLL `strmatch.dll` работает
в двух ролях.

## Две роли

**1) Внешняя компонента 1С 7.7 (1С++ AddIn, без регистрации в реестре).**
Загружается движком Орефкова (`_1Common/dev_serv.cpp`), как и `1sqlite.dll`:
```1c
ЗагрузитьВнешнююКомпоненту(КаталогПрограммы() + "strmatch.dll");
Об = СоздатьОбъект("StrMatch");        // или "СтрМатч"
Похожесть  = Об.Сравнить("панорама", "панор");      // -> 30  (сырой счёт)
Процент    = Об.Сравнить("панорама", "панор", 1);   // -> 100 (похожесть 0..100 %)
Версия     = Об.Версия();
```
Третий параметр `Сравнить(s1, s2, ВПроцентах)` необязателен (по умолчанию 0 —
прежнее поведение, сырой счёт). При `1` возвращается похожесть в процентах.

**2) Загружаемое расширение SQLite** (через 1sqlite):
```1c
База.РазрешитьЗагрузкуРасширений(1);
Зап.ВыполнитьЗапрос("SELECT load_extension('" + КаталогИБ() + "strmatch.dll')", 0);
р   = Зап.ВыполнитьЗапрос("SELECT strmatch('панорама','панор')",     0);   // -> 30
прц = Зап.ВыполнитьЗапрос("SELECT strmatch_pct('панорама','панор')", 0);   // -> 100
```
Функции: `strmatch(s1,s2)` — сырой счёт, `strmatch_pct(s1,s2)` — похожесть 0..100 %.
Точка входа расширения — `sqlite3_strmatch_init` (выводится из имени файла).

**Как считается процент:** сырой счёт нормируется на «само-счёт» более короткой
строки (её потолок при полном вхождении): `100 × strmatch(a,b) / min(strmatch(a,a),
strmatch(b,b))`, результат 0..100 %. Метрика асимметричная — меряет, насколько
короткая строка содержится в длинной (удобно для подбора).

Обе роли проверяются авто-тестами в `../1CTestBase/` (тесты `РасширениеStrmatch`
и `StrMatchВК`).

## Сборка

Тот же портативный VC6, что и для `1sqlite` (`../tools/MSVC600/`):
```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```
Результат: `build\strmatch.dll`.

## Ключевые детали реализации

- `StrMatchCtx.h` — контекстный класс `CStrMatchCtx : CContextImpl<CStrMatchCtx>`
  (`BL_BEGIN_CONTEXT("StrMatch","СтрМатч")`, методы `Сравнить`/`StrMatch`, `Версия`).
- `strmatch_reg.cpp` — `BL_INIT_CONTEXT(CStrMatchCtx)` (авто-регистрация класса,
  вынесена в отдельный TU, как `database.cpp` в 1sqlite).
- `StrMatchMain.cpp` — `DllMain`: `Init1CGlobal` + `InitAllContextClasses`.
- `strmatch_ext.cpp` — обёртка расширения SQLite (UTF-8 ↔ CP1251).
- `StrMatch_core.cpp` / `StrMatch.h` — исходный движок `CStrMatch` (Sk0rp).
- `strmatch.rc` — **обязательный** ресурс `STRINGTABLE { 100 "\0sd" }`: это
  сигнатура внешней компоненты 1С 7.7. Без неё 1С отвергает DLL в
  `ЗагрузитьВнешнююКомпоненту` (возвращает 0 и выгружает её).
- Сборка как MFC extension DLL: `_AFXEXT` **без** `_USRDLL` (иначе конфликт
  `DllMain` с `mfcs42.lib(dllmodul.obj)`), линковка с `/OPT:NOREF` (чтобы
  линкер не выкинул регистратор класса из секции `.blc`).
