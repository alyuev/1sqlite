# spellfix1 — пробное расширение SQLite для 1sqlite (нечёткий поиск + транслитерация)

Официальное расширение SQLite `ext/misc/spellfix.c` (public domain), собранное
**отдельной пробной сборкой** под наш портативный VC6. Грузится в 1sqlite как
обычное загружаемое расширение (`load_extension`) — **в саму 1sqlite не встроено**,
это отдельная `spellfix.dll`.

Главное, ради чего пробуем: **транслитерация кир↔лат**, дающая независимое от
алфавита сравнение строк, плюс расстояние редактирования и нечёткий словарь.

## Что даёт

| Функция / объект | Назначение |
|---|---|
| `spellfix1_translit(X)` | транслитерация Unicode → ASCII-латиница. `'Панорама'`→`'Panorama'`, `'Panorama'`→`'Panorama'`. Это и есть мост рус↔англ. |
| `editdist3(A, B)` | расстояние редактирования (Дамерау-Левенштейн). По умолчанию стоимость 1 правки = **100** (вставка/удаление/замена). `editdist3('панорама','паанорама')` = 100. |
| `spellfix1_editdist(A, B)` | расстояние по фонетическому хэшу. |
| `spellfix1_phonehash(X)` | фонетический хэш строки. |
| `spellfix1_scriptcode(X)` | код алфавита строки (латиница/кириллица/…). |
| `spellfix1` (vtab) | виртуальная таблица нечёткого поиска по словарю с ранжированием. |

## Подключение в 1С 7.7

```1c
ЗагрузитьВнешнююКомпоненту(КаталогПрограммы() + "1sqlite.dll");
База = СоздатьОбъект("SQLiteBase");
База.Открыть(":memory:");
База.РазрешитьЗагрузкуРасширений(1);
Зап = База.НовыйЗапрос();
Зап.ВыполнитьЗапрос("SELECT load_extension('" + КаталогИБ() + "spellfix.dll')", 0);
```

`spellfix.dll` положите рядом (в каталог ИБ или укажите полный путь). Точка входа
выводится из имени файла — `sqlite3_spellfix_init`, отдельно указывать не нужно.

## Кейс «искать русское название в строке на латинице»

Приводим обе стороны к латинице транслитом и сравниваем — алфавит больше не важен:

```1c
// 1) Точное совпадение независимо от алфавита:
//    lower(translit(a)) = lower(translit(b))
ТЗ = Зап.ВыполнитьЗапрос(
  "SELECT Код, Наименование FROM Справочник_Номенклатура
  | WHERE lower(spellfix1_translit(Наименование)) = lower(spellfix1_translit(:искомое))",
  СоздатьОбъект("ТаблицаЗначений"));   // :искомое — параметр

// 2) Нечётко (с опечатками), порог по расстоянию редактирования:
ТЗ = Зап.ВыполнитьЗапрос(
  "SELECT Код, Наименование,
  |        editdist3(lower(spellfix1_translit(Наименование)),
  |                  lower(spellfix1_translit(:искомое))) AS дист
  | FROM Справочник_Номенклатура
  | WHERE дист <= 200          -- не больше ~2 правок
  | ORDER BY дист",
  СоздатьОбъект("ТаблицаЗначений"));
```

`'Панорама'` найдёт строку `'Panorama'` и наоборот; с порогом `дист` — ещё и
`'Panaroma'`, `'Панарама'` и т.п.

## Виртуальная таблица spellfix1 (словарь нечёткого поиска)

Для повторяющегося поиска по большому справочнику — индекс-словарь:

```1c
// один раз: создать словарь и наполнить его (можно транслитом — кросс-скрипт)
Зап.ВыполнитьЗапрос("CREATE VIRTUAL TABLE dict USING spellfix1", 0);
Зап.ВыполнитьЗапрос(
  "INSERT INTO dict(word) SELECT spellfix1_translit(Наименование) FROM Справочник_Номенклатура", 0);

// поиск похожих на запрос (top-N, с расстоянием):
ТЗ = Зап.ВыполнитьЗапрос(
  "SELECT word, distance FROM dict
  | WHERE word MATCH lower(spellfix1_translit(:искомое)) AND top=10",
  СоздатьОбъект("ТаблицаЗначений"));
```

## Сборка

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```
Результат: `build\spellfix.dll`. Чистый C, без MFC. Под VC6 потребовалась одна
правка исходника (`5LL` → `(i64)5`, помечена в `spellfix.c`) и force-include
`../compat/vc6compat.h`.

## Статус

Пробная отдельная сборка. Если приживётся — `transliterate`/`editdist3` можно
будет встроить прямо в вариант 1sqlite (как FTS5), чтобы не грузить расширение
вручную. Проверено авто-тестом `Spellfix(кир/лат)` в `../1CTestBase/`.
