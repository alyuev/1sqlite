* Восстановление сборки

* Обновление движка SQLite 3.40 -> 3.53.2
+ Заново наложены все 1С-патчи на чистую амальгамацию: регистронезависимость кириллицы (oasUpper2Lower; stricmp/strnicmp/StrICmp по кодовым точкам; patternCompare), upper/lower через CharUpperW/CharLowerW, даты 1С (date1C, разбор ГГГГММДД, квартал), connect1CTable.
+ Перенесён фикс sqlite3StrIHash из 3.46 (имена полей на кириллице в разном регистре).
+ LIKE по индексу с кириллицей: отключена оптимизация LIKE->диапазон для не-ASCII префикса (решение автора из 3.42); полный LIKE через patternCompare корректен. Для поиска по подстроке — FTS5 trigram.

* Наши исправления и доработки
+ dateFunc: компактный вывод date('20240101')='20240101' для дат 1С.
+ typeField: маркер типа ':'/'$' распознаётся только ВНЕ строковых литералов. Иначе JSON-пути ('$.a'), объекты ('{"a":42}') и маски времени ('%H:%M:%S') в безымянной колонке принимались за тип 1С -> "Неправильная типизация в колонке".
+ to_base64 / from_base64 (UTF-8 <-> BASE64) зарегистрированы (рукописная реализация, не зависит от CDO).
+ Безопасный фикс пустой даты (ttDate): через локальный CDate, без прямой записи в чужую структуру CValue (та роняла 1С на реальной базе).
+ varchar(N) для строковых колонок в УложитьТЗ.
+ Исправлен КРАШ 1С при НЕтипизированном BLOB-результате: если объект BinaryData недоступен (минимальная конфигурация), BLOB отдаётся текстом, а не разыменовывается NULL-контекст (access violation).
