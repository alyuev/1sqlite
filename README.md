# 1sqlite — SQLite внутри 1С:Предприятие 7.7

Внешняя компонента (1С++ AddIn) для 1С:Предприятие **7.7**, встраивающая движок **SQLite** и дающая выполнять SQL-запросы прямо к нативным DBF-таблицам 1С (справочники, документы, журналы и т.д.), а также к собственным таблицам SQLite.

Проект начат **Александром Орефковым**, развивался **Антоном Азановым (Djelf)** (ум. октябрь 2025). Здесь — продолжение: восстановлена сборка, движок обновлён до **SQLite 3.53.2**, добавлены фиксы. Полная история изменений — в [`История.txt`](История.txt), история коммитов разработки — в [`ИСТОРИЯ_GIT.txt`](ИСТОРИЯ_GIT.txt).

Текущий релиз: **1sqlite 3.53.2.53**.

## Что умеет

- SQL-запросы к таблицам 1С 7.7 (автоподключение по имени: `Справочник_Номенклатура`, `Документ_РасходнаяНакладная`, …).
- Регистронезависимость кириллицы (значения, имена таблиц и полей, `LIKE`, коллация `_1C`).
- Типизация результата в типы 1С: `[поле:Число]`, `[поле:Дата]`, `[поле:Справочник.Вид]` и др.
- Даты 1С, `compress`/`uncompress` (zlib), `to_base64`/`from_base64`, математика, JSON; FTS5 — в отдельной сборке.
- Загрузка `ТаблицаЗначений`/объектов в SQLite и обратно.

## Структура репозитория

```
SQL_DBF/        исходники компоненты (C++) + build.ps1 + тест-обработка + документация
  SQLite/       пропатченная амальгамация sqlite3.c (под 1С и VC6)
_1Common/       фреймворк 1С++ (OneCpp) + 1CHEADERS (заголовки и импорт-либы 1С)
compat/         shim'ы для сборки современного SQLite под VC6 (stdint.h, vc6compat.h)
zlib/           zlib 1.3.1 + zlib.lib
1CTestBase/     пустая тест-база 1С 7.7 (справочник ТМЦ) + авто-тест «Тест 1SQLite.ert»
История.txt     changelog (Орефков → Djelf → продолжение)
ИСТОРИЯ_GIT.txt  история коммитов восстановления/доработки
```

## Сборка

Нужна ОС Windows. Тулчейн — **портативный Microsoft Visual C++ 6.0** (с MFC 4.2). Он проприетарный и в репозиторий **не входит** — скачайте отдельно.

1. Положите портативный VC6 в `tools/MSVC600/` так, чтобы получилось:
   - `tools/MSVC600/VC98/Bin/CL.EXE`, `tools/MSVC600/VC98/Include`, `tools/MSVC600/VC98/MFC`, `tools/MSVC600/VC98/Lib`
   - `tools/MSVC600/Common/MSDev98/Bin/RC.EXE`, `LINK.EXE`
   (подходит, например, портативная сборка MSVC600 от itsmattkc.)
2. Соберите одной командой из корня репозитория:
   ```powershell
   powershell -ExecutionPolicy Bypass -File SQL_DBF\build.ps1
   ```
   Результат: `SQL_DBF\build\1sqlite_built.dll`.
   Вариант с полнотекстовым поиском: `... build.ps1 -Fts5` → `1sqlite_built_fts5.dll`.

Скрипт сам выставляет окружение (PATH/INCLUDE/LIB на `tools/MSVC600`, `_1Common`, `compat`, `zlib`) — VCVARS вызывать не нужно.

## Использование в 1С 7.7

DLL ничего не экспортирует — она загружается как 1С++ AddIn:
```1c
ЗагрузитьВнешнююКомпоненту(КаталогПрограммы() + "1sqlite.dll");
База = СоздатьОбъект("SQLiteBase");
База.Открыть(":memory:");          // или путь к файлу .sqlite
Зап = База.НовыйЗапрос();
ТЗ  = Зап.ВыполнитьЗапрос("SELECT Код, Наименование FROM Справочник_Номенклатура", СоздатьОбъект("ТаблицаЗначений"));
```
Требуется установленная компонента **1С++ (OneCpp)**.

## Тест-база

`1CTestBase/` — пустая база 1С 7.7 со справочником ТМЦ и обработкой `Тест 1SQLite.ert`, которая при открытии прогоняет ~24 авто-теста и пишет лог в `1CTestBase/test_log.txt`. Положите рядом собранную `1sqlite.dll` (как `1sqlite.dll`) и откройте базу в 1С 7.7.
